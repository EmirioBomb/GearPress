## 🛠️ 关于本站

**GearPress** 使用 [VuePress 2](https://v2.vuepress.vuejs.org/) 与 [vuepress-theme-plume](https://github.com/pengzhanbo/vuepress-theme-plume) 构建，并在此基础上加入了个人主页、工具导航和自定义交互组件。

感谢所有为本站提供灵感与能力的开源项目。
