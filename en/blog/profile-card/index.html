About Profile Card

💡 Motivation

Why I built this?

Consistent profile style with improved visual presence

🎯 Goals

Info

  • ✅ Optimize layout and visual presentation
  • ✅ Improve hierarchy and styles

✍️ Implementation

  1. How to create

    Create .vuepress/theme/components/about/ProfileCard.vue
    <template>
  <section
    class="profile"
    :class="[
      `align-${align}`,
      boxMode === 'profile' ? 'box-profile' : '',
      isDark ? 'theme-dark' : 'theme-light'
    ]"
  >
    <div
      class="profile-banner"
      :class="[
        boxMode === 'banner' ? 'box-banner' : '',
        isDark ? 'theme-dark' : 'theme-light'
      ]"
    >
      <img
        src="https://cdn.jsdelivr.net/gh/EmirioBomb/media-collections@main/GearPress/profile/sticker.gif"
        width="100"
        class="profile-avatar is-static"
        alt="Status"
      />

      <img
        src="https://cdn.jsdelivr.net/gh/EmirioBomb/media-collections@main/GearPress/profile/profile.svg"
        class="profile-message is-static"
        alt="About Me"
      />
    </div>
  </section>
</template>

<script setup lang="ts">
import { useDark } from "@vueuse/core"

const props = withDefaults(
  defineProps<{
    align?: "left" | "center" | "right"
    boxMode?: "profile" | "banner"
  }>(),
  {
    align: "center",
    boxMode: "banner"
  }
)

/** 自动检测主题，根据主题调整卡片底色及hover效果 */
const isDark = useDark()
</script>

<style scoped>
.profile {
  display: flex;
  width: 100%;
}

.profile.align-left {
  justify-content: flex-start;
}

.profile.align-center {
  justify-content: center;
}

.profile.align-right {
  justify-content: flex-end;
}

.profile.box-profile {
  padding: 12px;
  border-radius: 16px;
  transition: all 0.25s ease;
}

.profile-banner {
  display: inline-flex;
  align-items: flex-end;
  gap: 10px;

  max-width: 100%;
  flex-wrap: nowrap;

  background: transparent;
  border: none;

  transition:
    transform 0.25s ease,
    box-shadow 0.25s ease,
    background-color 0.25s ease,
    border-color 0.25s ease;
}

.profile-banner.box-banner {
  padding: 10px;
  border-radius: 16px;
}

.profile-message {
  flex: 1;
  min-width: 0;
  max-width: 100%;
  height: auto;
}

.theme-light.box-profile:hover,
.theme-light.box-banner:hover {

  2. How to register

    Update .vuepress/theme/client.ts

    .vuepress/theme/client.ts
     import { defineClientConfig } from 'vuepress/client'
 import ProfileCard from './theme/components/about/ProfileCard.vue'

 export default defineClientConfig({
   enhance({ app }) {
       app.component('ProfileCard', ProfileCard) 
   },
 })

  3. How to use

    You can use this component anywhere, such as in posts or blogs.

    docs/README.md
    <ProfileCard />

    Warning

    When using this component on the homepage, remember to set type: custom in the Frontmatter, otherwise it won’t render properly.

    Click to show more

  pageLayout: home

  - type: custom
  ---

  4. Final Result

📖 Props

boxModeOptionalstring

banner

Controls the component’s visual style

  • profile: card style, full-width block layout with complete structural presentation
  • banner: banner style, inline content-only layout that does not span the full width

alignOptional'left' | 'center' | 'right'

center

Alignment

  • left: left-aligned
  • center: center-aligned
  • right: right-aligned

🚀 Usage

BoxModeDescriptionExamples
defaultDefault: banner<ProfileCard />
profilefull-width block layout<ProfileCard boxMode="profile" />
bannerinline content-only layout<ProfileCard boxMode="banner" />
alignment
  • left: left-aligned
  • center: center-aligned
  • right: right-aligned
<ProfileCard align="left"/>
