📌 什么是 iTerm2

注

iTerm2 是 macOS 平台上一款功能强大的 终端模拟器（Terminal Emulator），被广泛认为是系统自带 Terminal 的增强版。它提供了丰富的终端功能、更高的可定制性以及更优秀的开发体验，是许多开发者在 macOS 上的首选终端工具。

🚀 安装 iTerm2

下载并安装 iTerm2

✨ 增强美化 iTerm2

👀 最终效果 Argonaut 主题

1️⃣ 安装 Oh My Zsh

在安装 Oh My Zsh 时，会自动备份原始 .zshrc 为 .zshrc.pre-oh-my-zsh，这可能导致原有环境配置丢失。为了保留原配置，可以将 .zshrc.pre-oh-my-zsh 的内容追加到新 .zshrc 文件的末尾。

📥 curl
$ sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
⚡ wget
$ sh -c "$(wget https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh -O -)"

2️⃣ 安装 Powerlevel10k

Powerlevel10k 是一款高性能的 Zsh 主题，支持丰富的提示符信息展示和高度自定义配置，可帮助提升终端的可读性与使用体验。

🎨 安装字体

下载并安装 MesloLGS NF Font 字体，可根据需要选择其中一个版本

🎛️ 安装 Powerlevel10k Homebrew

$ brew install powerlevel10k
echo "source $(brew --prefix)/share/powerlevel10k/powerlevel10k.zsh-theme" >>~/.zshrc

3️⃣ 重启 Zsh

$ exec zsh

4️⃣ 配置 Powerlevel10k

重启 iTerm2 后，Powerlevel10k 可能会自动启动配置向导，按照提示完成配置即可。

如果需要重新配置，可执行以下命令再次启动向导：

$ p10k configure

⚙️ 配置iTerm2

可以通过快捷键 ⌘ + , 打开设置（Settings...）

1️⃣ 新建 Profile 并设为默认

打开菜单 Settings > Profiles > General，新建配置后，务必勾选 Set as Default，将其设为默认。

2️⃣ 禁用 Login Shell Optional

打开菜单 Settings > Profiles > General > Command，避免每次启动 iTerm2 时输出如下信息：

3️⃣ 设置字体

打开菜单 Settings > Profiles > Text > Font， 请参照： Meslo Nerd Font 字体

4️⃣ 设置配色

下载 Iterm2-color-schemes 配色方案，并将其导入到 iTerm2，支持 批量导入。

个人偏好的 配色
  • Argonaut
  • Aura
  • Banana Blueberry
  • Cool Night
  • Dark Pastel
  • Duckbones
  • Fahrenheit
  • Floraverse
  • Glacier

⚠️注： 若想批量删除配色方案，可参考 Bulk remove iTerm2 color schemes

打开菜单 Settings > Profiles > Colors > Color Preset

5️⃣ 设置状态栏 Optional

打开菜单 Settings > Profiles > Sessions > Status Bar

6️⃣ 启用 Minimal 主题

打开菜单 Settings > Appearance > General > Theme，将 Regular 更改为 Minimal

7️⃣ 安装 zsh-syntax-highlighting Optional

zsh-syntax-highlighting 是一个 Zsh 插件，可在命令行中 实时高亮 输入的命令，提高可读性并减少错误。

# 1. 安装
$  brew install zsh-syntax-highlighting

# 2. 设置环境变量
$ echo "source $(brew --prefix)/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh" >> ${ZDOTDIR:-$HOME}/.zshrc

# 3. 重启 zsh
$ exec zsh

8️⃣ 安装 zsh-autosuggestions Optional

zsh-autosuggestions 是一个 Zsh 插件，可根据历史命令 实时提供输入建议，提高命令行输入效率。

# 1. 安装
$  brew install zsh-autosuggestions

# 2. 设置环境变量
$ echo "source $(brew --prefix)/share/zsh-autosuggestions/zsh-autosuggestions.zsh" >> ${ZDOTDIR:-$HOME}/.zshrc

# 3. 重启 zsh
$ exec zsh

9️⃣ 安装 fastfetch Optional

fastfetch是一个类似 Neofetch 的轻量级命令行工具，用于在终端快速显示系统信息和硬件配置。

$  brew install fastfetch

🔧 Visual Studio Code 字体

可以通过快捷键 ⌘ + , 打开设置，并查询 terminal.integrated.font

⚠️注: 字体名为 MesloLGS NF
